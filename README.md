# DalaSpace — Мониторинг сельского хозяйства Казахстана

Платформа спутниковой аналитики и ИИ-анализа полей Казахстана (17 регионов).

## Запуск проекта

1. Установите зависимости:
```bash
npm install
```

2. (Опционально) Скопируйте `.env.example` в `.env` и укажите ваш Anthropic API Key:
```bash
cp .env.example .env
```

3. Запустите dev-сервер:
```bash
npm run dev
```

4. Сборка для продакшена:
```bash
npm run build
```
